# Backend & Agronomic Rule Engine

Thư mục chứa dịch vụ Backend xử lý dữ liệu IoT và phân tích nông học:
- Framework: Python FastAPI
- Giao thức: MQTT Client (paho-mqtt), REST API, WebSocket/SSE
- Core: Agronomic Rule Engine đối chiếu chỉ số đất (NPK, pH, EC) với ngưỡng của cây trồng.
- Xem đặc tả tại [SPECIFICATION.md](../SPECIFICATION.md).
